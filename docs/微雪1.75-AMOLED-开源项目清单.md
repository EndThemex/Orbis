## 0. 先对号：你手上是哪块板

「微雪 1.75 触控屏」在市面上对应多代硬件，引脚、卡槽、Flash 容量都不同，选错项目会导致驱动和引脚全部对不上。

| 型号 | 主控 | 屏 / 触摸 | Flash | TF 卡槽 |
|---|---|---|---|---|
| **ESP32-S3-Touch-AMOLED-1.75** | ESP32-S3R8 | 1.75" 466×466 圆 AMOLED，CO5300 QSPI / CST9217 I2C | 16 MB | ✅ 有 |
| ESP32-S3-Touch-AMOLED-1.75**-B** | 同上 | 同上 | 16 MB | ✅ 有（自带外壳） |
| ESP32-S3-Touch-AMOLED-1.75**-G** | 同上 | 同上 + GNSS | 16 MB | ✅ 有（GPIO17/18 被 GNSS 占用） |
| ESP32-S3-Touch-AMOLED-1.75**C** | ESP32-S3R8 | 同上 | **32 MB** | ❌ 无 |
| RP2350-Touch-AMOLED-1.75 | RP2350 | 同款屏 | — | — |
| 1.75inch AMOLED 裸模组 | 需自配 | 同款屏 | — | — |

同款屏还带：AXP2101（电源管理）、QMI8658（六轴）、PCF85063（RTC）、ES7210（双麦）、ES8311（功放）。

**结论**：本文所有 ESP32-S3 项目默认按「1.75 标准版」适配；1.75C 需要单独确认移植状态（多数项目没有卡槽兜底逻辑）。

## 附录 A：TamaPoke 本地部署记录

已在本机完成实机部署，硬件为 **ESP32-S3-Touch-AMOLED-1.75 标准版**。

| 环节 | 结果 |
|---|---|
| 芯片识别 | COM9 · `VID 303A:PID 1001` · MAC `90:70:69:fd:bf:98` · 16MB Flash + 8MB PSRAM |
| 固件版本 | v1.22（commit `a441be2`） |
| 烧录 | esptool 5.7.0，921600 bps，哈希校验通过 |
| 偏移 | `0x0` bootloader / `0x8000` partitions / `0xe000` boot_app0 / `0x10000` app（**跳过 NVS 保存档**） |
| SD 卡 | 64GB 原为 RAW 状态，上电后固件自动格式化为 FAT32，挂载 59638 MB |
| 精灵资源 | `tools/send_sd.py` 推送 303 个文件 / 41MB / 约 120 KB/s / 6 分 46 秒 |
| 启动验证 | `miniaturas cargadas: 151` + `cargado /mons/p001.bin` |

**命令备忘**

```bash
# 烧录（跳过 NVS）
python -m esptool --chip esp32s3 -p COM9 -b 921600 write-flash \
  0x0 firmware/bootloader.bin 0x8000 firmware/partitions.bin \
  0xe000 firmware/boot_app0.bin 0x10000 firmware/app.bin

# 推送精灵到 SD（走固件内置 PUT 协议）
python tools/send_sd.py --port COM9

# 列出卡内文件
python tools/send_sd.py --port COM9 --ls
```

**坑位记录**

1. pip 默认源（清华镜像）没有 esptool，必须 `-i https://pypi.org/simple`。
2. Windows 无法把 >32GB 的卡格式化成 FAT32 —— 但 TamaPoke 的 `SD_MMC.begin(..., true)` 第三参数是 `format_if_mount_failed`，插上板子开机会自动格式化。**副作用是：卡挂载失败会被直接抹掉**，调试期建议先改 `false`。
3. 不要用 `web/firmware/tamapoke.bin`（写 `0x0` 全片，会用 0xFF 冲掉 NVS 存档）。
4. 编译需 `PSRAM=opi` + 带 FAT 的分区表：`esp32:esp32:esp32s3:CDCOnBoot=cdc,FlashSize=16M,PSRAM=opi,PartitionScheme=app3M_fat9M_16MB`。

## 附录 B：引脚速查（1.75 标准版）

| 功能 | 信号 | GPIO |
|---|---|---|
| 屏幕 CO5300 | CS / SCLK / D0-D3 / RST / TE | 12 / 38 / 4-7 / 39 / 13 |
| 触摸 CST9217 | SDA / SCL / INT / RST / addr | 14 / 15 / 11 / 40 / `0x5A` |
| TF 卡（1-bit SDMMC） | CMD / CLK / D0 / D3(未用) | 1 / 2 / 3 / 41 |
| 音频 | ES8311 功放 / ES7210 双麦 | 见官方 HARDWARE_REFERENCE |

> TF 卡无 CD（插入检测）与 WP（写保护），只能靠挂载成功与否判断。挂载期间**禁止复用 GPIO1/2/3**，否则锁死总线。
